Entry for the make.fun competition
[Famous Last Words: The Funniest Epitaph](https://make.fun/competitions/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406):
a program that writes the funniest possible one-line tombstone epitaph.

## The entry

> Here lies Tom. He always said he'd sleep when he was dead. He was right.

One line, 72 characters. It opens in a true epitaph voice ("Here lies
Tom"), borrows the familiar boast "I'll sleep when I'm dead", and then the
stone itself delivers the verdict in three words: he was right. The joke
needs no setup beyond the cliché, the twist is the dead man being proved
right by his own tombstone, and the whole line reads like something
actually carved — short, final, and easy to repeat to a friend.

## How to run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (creating `/output` if needed).
The output is deterministic: running it twice produces byte-identical files.
